# Spineplay 0.3.2 — first public beta

**Audiobooks for Plex.** A free Android audiobook player with no ads or in-app purchases.

Download **Spineplay-0.3.2.apk** below and open it on an Android 8.0+ phone or tablet. Sign in through Plex and choose the libraries containing your books. You need your own Plex account and access to a reachable server; no books are included.

## Included

- Remembered Plex Home profile, server and library choices.
- Resume-first library with search, author/series browsing, reading filters and Listen later.
- Separate chapter and whole-book progress, precise seeking, bookmarks, listening History and Undo jump.
- Books open paused until you press Play. Explicit Play/Resume actions start listening.
- Whole-book downloads for offline listening.
- Playback speed, smart rewind, remembered sleep timer, gentle fade and return to bedtime start.
- Durable Plex position updates, recoverable position conflicts and optional verified folder backups.
- Exact-edition chapter lookup through Audnexus and clearly labelled listening sections where chapter data is absent.
- Spineplay branding and a short, silent, skippable launch animation.

## Existing private testers

This APK retains the previous signing certificate, so install it **over your existing app** to preserve local records and downloads. Export a progress backup before changing installations. Updates from GitHub are currently manual.

## Validation and limits

All 47 automated tests pass, release lint has no errors, and the APK's signature is verified. Source publication and the packaged APK were scanned for secrets. The README screenshots use fictional sample content.

This remains a beta: real-device testing continues for foreground playback/downloads, accessibility, folder providers and two-device progress. Plex updates are best effort; bookmarks/history/reading flags are not live-synced between phones. Sonos Wi-Fi casting, Chromecast and Android Auto are not implemented.

The APK is a non-debuggable release variant signed with the existing development certificate for compatibility. It is not a Google Play production-signed release. No signing keys, Plex credentials, personal library or audio are included in the source or release assets.

Use **SHA256SUMS.txt** to check the APK download, and **SIGNING-CERTIFICATE.txt** to identify the public signer certificate. Report issues at https://github.com/smartdevuk/spineplay/issues after removing private information from logs/screenshots.
